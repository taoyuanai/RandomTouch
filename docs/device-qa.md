# Mock 全页面三态 + 真机视觉回归清单

> 不需要后端、IP、域名。保持 `services/config.js` 的 `USE_MOCK=true`。
> 真机预览前在微信开发者工具中登录并扫码；若用 CLI/自动化，需要开启
> `设置 → 安全设置 → 服务端口`。

## 一、准备

- [ ] 微信开发者工具打开项目，基础库为当前稳定版
- [ ] 清缓存后重新编译
- [ ] 真机预览：iPhone 一台 + Android 一台（重点不同安全区/胶囊）
- [ ] `DEBUG` 临时改为 `true` 才可使用控制台故障注入；回归完恢复 `false`
- [ ] 不修改 `RELEASE=false`，不切真实 API

## 二、三态

### Loading

- [ ] 冷启动首页：出现骨架/首屏，不白屏
- [ ] 订阅页：feed 未返回前有 loading，不闪空态
- [ ] 详情/抽卡/全图：先显示骨架或占位，不出现 0/0 假数据
- [ ] 首次进入作者/收益/创作：不出现未定义字段

### Empty

- [ ] 首页筛选无结果：空态文案 + 分类 chips 可切回
- [ ] 搜索无结果：空态 + 清空重搜
- [ ] 订阅页无待办：去发现按钮可用
- [ ] 创作中心无作品：新建入口可用
- [ ] 详情无进度：CTA 正确，不出现空卡面
- [ ] 全图未抽：暗格不显示卡面文字

### Error / Retry

在控制台：

```js
getApp().__apiDebug.setFailureRate(1)
```

- [ ] 首页 onShow 失败：`bootError` 提示与重试入口可见
- [ ] 订阅页失败：不白屏，恢复后可重新加载
- [ ] 收益 / 作者失败：不丢已有内容，恢复后刷新
- [ ] 详情失败：不标记已加载，重试可恢复
- [ ] 故障恢复：

```js
getApp().__apiDebug.setFailureRate(0)
```

- [ ] 首页/订阅/详情/收益/作者恢复后数据正确
- [ ] 抽卡失败：不重复扣次数，可再抽
- [ ] 盖戳失败：不误显示已盖戳，可重试
