# 今日做点小事 · 微信小程序版

把远程仓库 `git@github.com:taoyuanai/RandomTouch.git` 中的 **「今日做点小事」V2.3c 完整产品原型**（`static/day_small_things_v2.html`）原生移植到微信小程序。

不是 `web-view` 套壳：页面、样式、动效、状态机都按小程序原生 `WXML / WXSS / JS` 重写，打开微信开发者工具即可直接预览。

## 快速开始

1. 用微信开发者工具打开本目录（`project.config.json` 已就绪）。
2. 开发者工具会使用当前登录账号可用的测试 AppID（本项目在导入时由工具自动写入 `project.config.json`）；若工具提示未登录，先扫码登录。
3. 点击「编译」，从「发现」页开始体验。
4. 如需真机预览或上传体验版，把 `project.config.json` 的 `appid` 换成你自己的小程序 AppID。

> 首次打开如果仍显示旧模板页面，在开发者工具里点一次「编译」或清缓存即可。

## 原型控制台入口

原网页有一个外部 devbar；小程序里没有手机壳外的空间，因此把入口藏在了：

**「发现」页 → 长按顶部日期**。

进入「组件总览」后可以：

- 切换「新用户 · 空态 / 演示用户 · 有进度」
- 切换「创作者 · 零作品」
- 一键快进「云的图鉴」到抽空态（含 3 枚邮戳）
- 预览 N / R / SR / SSR 动画海报

## 文件结构

```
app.js / app.json / app.wxss      小程序入口；自定义导航、白色背景
data.js                           从原型 DEMO / CRAFT / FANS / TXN_SEED 移植的演示数据
assets/icons/*.png                由原型内联 SVG 栅格化得到的图标（tabbar / 搜索 / 相机 / 火漆等）
pages/index/index.js              全部产品状态机与页面逻辑
pages/index/index.wxml            所有页面、弹层、模板（单页 SPA）
pages/index/index.wxss            V1「白底多彩」设计系统原样移植 + 小程序适配层（暖纸覆盖层已中和回 V1）
project.private.config.json       Skyline 关闭，使用 WebView 渲染以兼容这套 CSS
```

## 和网页原型的差异

- 网页原型的 `.phone` 手机壳改为全屏小程序页面；顶部为自定义导航，已按胶囊按钮位置预留安全区。
- 页面由 `.screen` 内部滚动改为小程序页面滚动；吸底 CTA、底部 tabbar、弹层改为 `position: fixed`。
- 原生 `button` 做了样式重置；`input / textarea` 使用小程序原生组件；拍照使用 `wx.chooseMedia`。
- 内联 SVG 图标改为本地 PNG 图标；印戳日期由 CSS `attr(data-date)` 改为真实文本。
- 数据仍在内存里（与原型一致，刷新/重启恢复初始状态），不调用后端。
- 「保存到相册」与原网页原型一样是演示提示；真正保存图片需要接 Canvas / 服务端出图。
- 仓库里上一版「拾笺」服务端抽卡（`geo/`、`templates/gacha.html`）在当前系统中标记为遗留模块，未移植。
- 远程仓库的 Flask 服务、`.env`、日志等不参与小程序运行。
