# 今日做点小事 · 微信小程序版

把远程仓库 `git@github.com:taoyuanai/RandomTouch.git` 中的 **「今日做点小事」V2.3c 完整产品原型**（`static/day_small_things_v2.html`）原生移植到微信小程序。

不是 `web-view` 套壳：页面、样式、动效、状态机都按小程序原生 `WXML / WXSS / JS` 重写，打开微信开发者工具即可直接预览。

## 快速开始

1. 用微信开发者工具打开本目录（`project.config.json` 已就绪）。
2. 开发者工具会使用当前登录账号可用的测试 AppID（本项目在导入时由工具自动写入 `project.config.json`）；若工具提示未登录，先扫码登录。
3. 点击「编译」，从「发现」页开始体验。
4. 如需真机预览或上传体验版，把 `project.config.json` 的 `appid` 换成你自己的小程序 AppID。

> 首次打开如果仍显示旧模板页面，在开发者工具里点一次「编译」或清缓存即可。

## 已移植的功能

- **发现**：整页纵向滚动（页头随内容一起上移，不做吸顶）；品牌日期 + 搜索栏 + 三宫格快捷区（分类→滚动到 chips / 热门活动→最热榜单 / 新建卡片→创作中心）+ slogan + 分类 chips + 热门/最新排序；卡集列表为圆角浮起方框卡（封面、价格/试抽、状态、热门与心动标签），不再使用去盒子化的分割列表。
- **卡集详情 v2**（原型 V2.3c 同步）：set-hero 大封面签（竖排双列字 + 价格/试抽徽标）、集名/类型/分类/热度行、🔒待解锁金胶囊、简介 + 创作者卡（头像/关注者数/关注按钮）、收集进度卡（N/M 张 + 渐变进度条 + 抽空日期预测 + 邮戳进度 + 试抽进度 +「看全图 · 暗格不剧透」跳全图页）、题眼元信息、怎么玩一行摘要；主操作 CTA 前置到首屏，滚动后由浮动 CTA 接力。
- **卡集分享 / 深链**：详情页右上角「分享」，分享标题为「《卡集名》· 今天来抽一签」，路径携带 `sid`；冷启动 / 热启动解析 `sid` 后直达卡集详情，并显示「朋友请你来抽一张」；无效 id 回首页提示；朋友圈分享携带 `sid` query。
- **题眼（作者签名）**：四档稀有度下线，作者在编辑器可选一张「本集题眼」并写 ≤30 字附言；抽卡金色顶栏与金章晚于卡词 500ms 出现；全图题眼格金描边，卡背增加「✦ 附言」层，海报/纪念册使用题眼金章。
- **抽卡**：竖版信封、火漆、开启动画、卡片 3D 翻面、题眼金色签名与延迟落章、收入卡包 / 分享海报；每次抽卡后显示「心动 + 留一句」回响条，不写回信也可参与卡集互动。
- **回信 / 邮戳**：卡背记录、拍照/相册选图（选图后进入固定 4:3 比例的原生裁剪，可拖动缩放取景）、一句话记录、钢印落章动画、海报携带回信；卡背与海报照片使用同一 4:3 比例，避免二次裁切。
- **卡集互动**：详情页「心动」一键点亮（空心 ↔ 橙色实心 + 数字动画），以及「签友留言」半屏；订阅且抽过该卡集后才能留言，未抽时显示引导入口。首页卡集的「热门 / 价格」标签旁同步显示心动数。
- **推荐卡集**：详情页底部「相关推荐 / 最近热门」三宫格，可换一批；抽卡后显示「再抽抽看」，只推荐今日还可抽的卡集；抽空后金色弹层显示「下一集在等你」推荐，并可去发现更多。
- **订阅 v2**：顶部本周目标卡（7 天点阵、集满金色引导装订周记、点击直达今日待办；每周一 0 点重置、缺勤不罚）+ 行动提醒卡（🔔 今日可抽直达抽卡 / ✉️ 等你回信直达盖章面板）+ 三格统计（今日可抽/已抽的卡/已抽空）+ 三组卡片（今日可抽 / 已订阅 / 已集齐，橙点分组头 + 计数徽标 + 竖排小签卡行）。
- **订阅消息**：首次抽卡揭示后、首次盖邮戳后各主动询问一次授权（全生命周期最多 2 次）；「我的 · 设置」可开启/关闭每日提醒，三档时段 08:00 / 12:30 / 21:00，默认 21:00；预览环境 `wx.requestSubscribeMessage` 自动同意。
- **回流承接**：订阅消息携带 `from=remind` 启动时直达订阅页（只路由一次）；≥3 天未抽时订阅页顶部显示「好久不见」问候卡，缺席天数与可抽数量均来自真实状态，今天抽卡后自动消失。
- **创作中心**：顶部统计为上架中 / 关注者 / 获赞；审核中与草稿数量保留在下方分组标题；含收益入口、新建卡集。
- **编辑器 / 上架闭环**：卡集封面（固定 3:4 上传裁剪，建议 900×1200，上架必填）、标题、简介、类型、分类、定价、逐张卡片编辑、五条校验、锁死确认、审核中只读；首页与详情页优先展示图片封面，旧数据回退系统封面。
- **收益看板**：累计收益、可提现 / 处理中 / 已提现、收益构成、逐笔明细、满 ¥100 提现。
- **我的 / 创作者主页**：身份头、旅程统计、今日状态、「怎么玩」摘要卡（打开完整规则半屏）、菜单、作品/被抽/关注者、关注与作品列表；卡集详情保留一行玩法摘要，不再铺开五条规则。
- **海报 / 纪念册**：单卡高亮海报（题眼金章 / 普通卡无概率视觉）、抽空纪念海报、双档纪念册（基础版 / 满页纪念版）。

## 自建后端（Phase 2，测试环境先行）

- 服务端：`server/` —— Node 20 + Express + MySQL + Redis + 腾讯云 COS，实现 `contract.md` v1 全部 22 个方法。
- 接入层：`services/real/index.js`；开关在 `services/config.js`（`USE_MOCK` / `API_BASE`），页面与 `lib/` 零改动。
- 部署：`deploy/test/bootstrap.sh` 幂等脚本 —— 建系统账号 `rt-test`、测试目录 `/data/project/randomtouch/test`、库 `randomtouch_test`、Redis db1 前缀 `rt:test:`、systemd 与 Nginx。
- 详见 [server/README.md](server/README.md) 与 [deploy/test/README.md](deploy/test/README.md)。
- v1 说明：`unlock` / `withdraw` 为模拟支付（契约定义）；图片上传经服务端写 COS，后续可换 STS 直传。

## 内容安全 P0-1（Phase 2 接入）

- 客户端 Phase 1 已移除 `utils/security.js`；留言、邮戳、封面、投稿统一走 `services/api.js`。
- 自建后端在 `server/src/services/sec.js` 直连微信 OpenAPI（msgSecCheck / mediaCheckAsync）；
  `SEC_MODE=mock` 供测试环境放行，正式环境改 `real`。
- 云端脚手架保留：`cloudfunctions/auth`、`cloudfunctions/sec`、`cloudfunctions/sec-callback`、`cloudfunctions/qrcode`（不再依赖，可择机下线）。
- 私有邮戳 fail-open、留言 fail-closed、卡集机审/人工队列规则保持不变，由服务端返回状态。

上线前需要：
1. 完成 `services/real/index.js`（已提供），在 `services/config.js` 设 `USE_MOCK=false` 并填 `API_BASE`
2. 在服务器 `.env` 填 `WX_SECRET` / `COS_*`，`SEC_MODE=real`
3. 在小程序后台配置 request / uploadFile / downloadFile 合法域名（含 COS 域名）
4. 在公众平台完成用户隐私保护指引声明（相册/摄像头/保存相册/裁剪）
5. 用真实模板联调文本与图片样本；`DEBUG=false` 后方可提审

## 和网页原型的差异

- 4 个 tab 页使用原生导航 + 原生 tabBar；set 用原生导航，draw 用沉浸式 custom 导航。
- 页面由 `.screen` 内部滚动改为小程序页面滚动；吸底 CTA、底部 tabbar、弹层改为 `position: fixed`。
- 原生 `button` 做了样式重置；`input / textarea` 使用小程序原生组件；拍照使用 `wx.chooseMedia`。
- 内联 SVG 图标改为本地 PNG 图标；印戳日期由 CSS `attr(data-date)` 改为真实文本。
- 业务数据走 mock 内存（重启恢复初始）；创作草稿单独持久化到本地 storage。
- 「保存到相册」与原网页原型一样是演示提示；真正保存图片需要接 Canvas / 服务端出图。
- 仓库里上一版「拾笺」服务端抽卡（`geo/`、`templates/gacha.html`）在当前系统中标记为遗留模块，未移植。
- 远程仓库的 Flask 服务、`.env`、日志等不参与小程序运行。
