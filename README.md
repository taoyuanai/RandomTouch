# 今日做点小事 · 原型 V2.3c（完整产品 + 设计系统合并）

当前页面保留 V2.3b 的完整产品功能（11 个页面、编辑器、上架闭环、收益、我的、创作者主页、全图/抽空、动态数据），并增量合并 V2.3c 的设计与动画内容。**不是整页替换为静态原型。**

## 当前功能

- **发现**：搜索、快捷入口、分类筛选、热门/最新排序、卡集列表。
- **卡集详情**：关注、收集进度、稀有度分布、规则与底部固定抽卡按钮。
- **抽卡**：拆信封、翻卡、稀有度水印与色条、收入卡包 / 分享海报。
- **订阅**：今日可抽 / 已抽 / 已抽空统计与已订阅卡集。
- **创作中心**：上架中 / 审核中 / 草稿统计、收益入口、新建、审核中 / 草稿 / 已上架分组。
- **编辑器 / 上架闭环**：字段编辑、逐张卡片、五条校验（含 8 张起）、锁死确认、审核中只读、通过审核后进入发现。
- **收益看板**：累计收益、可提现 / 处理中 / 已提现、收益构成（付费 80% 分成 + 免费集平台激励）、逐笔明细、满 ¥100 提现。
- **我的 / 创作者主页**：身份头、创作区菜单、作品 / 被抽 / 关注者、关注与作品列表。
- **组件总览（dev-only）**：金色 SSR、稀有度配色、分布条、按钮、动画海报预览。

## V2.3c 增量合并

- 新增金色 SSR token：`--gold-50…--gold-700`，SSR 徽章、稀有度条、卡面水印、全图圆点、海报统一为金色。
- 稀有度圆点改为 mint / sky / honey / gold 四色。
- 海报改为 V2.3c 的动画高亮版式：稀有度大字、动态日期、`poster-setinfo`、SSR shine，并继续使用当前动态卡集/卡片数据。
- 卡面水印随抽到的稀有度同步更新（原实现固定为 N）。
- 新增 dev-only「组件总览」页与 devbar 入口，不影响主流程。
- 按最新 body 页面优化：信封移除「抽」火漆；订阅页头部恢复默认 brand-row 间距。
- 吸收最新脚本的卡集内容：更新「醒来觉得甚是爱你」「冬天的二十四个词」词库与文案；新增「咖啡风味轮」「城市漫步者词典」「睡前一首诗」「心理防御机制图鉴」「云的图鉴」「便利店哲学」；新增创作者与「生活 / 味觉 / 心理 / 自然」分类；封面标签缩短以适配长标题。
- 保留原有卡集、编辑器、上架、收益、我的、创作者主页等功能。
- 保留此前的防页面闪烁、防抖动修复。

## 规则同步（2026-11-13）

按最新 V2.3c 实现同步，当前规则以这一版为准：

- 付费卡集每个卡集 **1 次免费试抽**，试抽不占每日额度；解锁后立即送一张当日签。
- 上架门槛：至少 **8 张完整卡**；新建草稿预置 8 个卡位（N/N/N/R/R/N/SR/SSR）。
- 定价阶梯：**免费 / ¥6 / ¥12 / ¥19**，付费集自动含 1 张试抽。
- 提现门槛：**满 ¥100**，文案为「提现到微信零钱」。
- 收益模型：付费卡集解锁分成 **80%** + 免费卡集**平台激励**（按抽签量）；新增「周一生存指南」演示集用于展示两条收入。
- 收藏集从**剩余池随机**取牌，不再按顺序发牌；抽空后卡集页显示「看抽空纪念」。
- 抽卡页、卡背、抽空海报同步新版文案：`No.XX / 总数`、`集齐啦`、`薄荷 / 晴空 / 蜜琥珀 / 鎏金`。
- 我的页新增「点亮张数 / 订阅卡集 / 关注的人」统计；创作中心统计改为「上架中 / 审核中 / 草稿」。
- 「新用户·空态」同时隐藏创作者已上架卡集、草稿与审核中作品；切回「演示用户·有进度」恢复。

未迁移：V2.3c 的静态路由/抽卡状态、硬编码海报数据、整份样式/脚本、把海报弹层放到手机壳外的布局。
