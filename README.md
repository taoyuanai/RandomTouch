# 今日做点小事 · 原型 V2.4（完整产品 + 回信与邮戳）

当前页面在 V2.3b 完整产品与 V2.3c 设计/动画基础上，增量合并 **V2.4a–V2.4h「回信与邮戳」**：卡背回信、邮戳分发、双档纪念册、「我的」改版、明信片卡背、道具化信封、钢制日期印戳、分享海报携带回信。**不是整页替换为静态原型。**

## 当前功能

- **发现**：搜索、快捷入口、分类筛选、热门/最新排序、卡集列表。
- **卡集详情**：关注、收集进度、邮戳进度、稀有度分布、规则与底部固定抽卡按钮；今日已抽未回信时按钮变为「盖个邮戳」。
- **抽卡**：竖版信封 + 火漆拆封、卡升起、翻卡、稀有度水印与色条；卡背三态「信 / 手写的信 / 明信片」；收入卡包 / 分享海报。
- **订阅**：今日可抽 / 已抽 / 已抽空统计、已订阅卡集、今日待抽 banner 与「N 张卡在等你回信」banner。
- **创作中心**：上架中 / 审核中 / 草稿统计、收益入口、新建、审核中 / 草稿 / 已上架分组。
- **编辑器 / 上架闭环**：字段编辑、逐张卡片、五条校验（含 8 张起）、锁死确认、审核中只读、通过审核后进入发现。
- **收益看板**：累计收益、可提现 / 处理中 / 已提现、收益构成（付费 80% 分成 + 免费集平台激励）、逐笔明细、满 ¥100 提现。
- **我的 / 创作者主页**：身份头整卡可点、旅程统计（已集的卡 / 已盖邮戳 / 已抽空）、今日一行、创作区菜单；创作者作品 / 被抽 / 关注者。
- **抽空纪念 / 纪念册**：抽空页双档入口；基础版抽空即解锁，满页纪念版需全部盖满邮戳，金色封面 + 专属结语。
- **组件总览（dev-only）**：金色 SSR、稀有度配色、分布条、按钮、动画海报预览。

## V2.4 增量（回信与邮戳）

- **V2.4a 回信与邮戳**：卡背新增回信位；记录弹层支持拍照 / 相册或最多 50 字；收藏集一卡一记（可修改），常驻集每次一张累计展示最新一条。
- **V2.4b 回信分发网络**：详情页邮戳进度、全图相机/钢戳角标、订阅页回信 banner、「我的」今日一行与待回信提醒。
- **V2.4c 纪念册双档制**：抽空即得基础版；所有已抽卡都盖满邮戳后解锁满页纪念版。
- **V2.4d 「我的」页改版**：身份头整卡可点进创作者主页；旅程统计改为「已集的卡 / 已盖邮戳 / 已抽空」。
- **V2.4e 明信片式卡背**：无记录保留信形态；只有文字时为手写的信；有照片时为 65% 出血大图 + 文字条的明信片。
- **V2.4f 信封道具化**：竖版信封（308×448）包住卡（280×420），火漆碎裂 → 盖口翻开 → 信封退场 → 卡升起落定。
- **V2.4g 钢制日期印戳**：方正黑色双线钢框、Courier 打字机数字、手盖重影与油墨不均；界面仍显示「11月8日」，印戳显示 `2026.11.08`。
- **V2.4h 分享海报携带回信**：大卡 / 抽卡页记录当前卡，用户主动分享时回信随卡出境；无记录或无文字时不占位。
- **验收工具**：devbar 新增「演示 · 抽空『云的图鉴』」，预置 3 枚邮戳，用于查看双档纪念册。

## V2.4 规则

- 回信只给自己看；不记录也不影响抽卡、收集与任何其他功能。
- 收藏集一卡一记，可修改；常驻集同一卡可「再记」，按次数累计。
- 纪念册基础版在抽空后即可生成；满页纪念版要求所有已抽到的卡都盖上邮戳。
- 海报携带回信属于用户主动分享（opt-in），站内回信完全私有。
- 回信图片使用浏览器本地 `URL.createObjectURL`，刷新页面后恢复初始演示数据。

## 规则同步（2026-11-13）

按最新实现同步，当前规则以这一版为准：

- 付费卡集每个卡集 **1 次免费试抽**，试抽不占每日额度；解锁后立即送一张当日签。
- 上架门槛：至少 **8 张完整卡**；新建草稿预置 8 个卡位（N/N/N/R/R/N/SR/SSR）。
- 定价阶梯：**免费 / ¥6 / ¥12 / ¥19**，付费集自动含 1 张试抽。
- 提现门槛：**满 ¥100**，文案为「提现到微信零钱」。
- 收益模型：付费卡集解锁分成 **80%** + 免费卡集**平台激励**（按抽签量）；新增「周一生存指南」演示集用于展示两条收入。
- 收藏集从**剩余池随机**取牌，不再按顺序发牌；抽空后卡集页显示「看抽空纪念」。
- 抽卡页、卡背、抽空海报同步新版文案：`No.XX / 总数`、`集齐啦`、`薄荷 / 晴空 / 蜜琥珀 / 鎏金`。
- 我的页新增「点亮张数 / 订阅卡集 / 关注的人」统计；创作中心统计改为「上架中 / 审核中 / 草稿」。
- 「新用户·空态」同时隐藏创作者已上架卡集、草稿与审核中作品；切回「演示用户·有进度」恢复。

未迁移：V2.3c 的静态路由/抽卡状态、硬编码海报数据、整份样式/脚本、把海报弹层放到手机壳外的布局。
